# Mascha

Öffentliche Seite der Strick-App **Mascha** mit der Datenschutzerklärung
(für den Google Play Store).

Die Seite wird mit GitHub Pages veröffentlicht: `index.html` im Hauptordner.
Die Datenschutzerklärung wird im (privaten) App-Repository gepflegt
(`docs/datenschutz.md`) und von dort nach `index.html` übertragen.
